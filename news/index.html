Project timeline

Updates

Chronological record of dataset releases, publication milestones and catalogue changes.

202617 August

Official WindsorML train, validation and test splits are now available. The release defines eight deterministic benchmark regimes: an approximately 80/10/10 random baseline, three nested data-efficiency subsets, and four out-of-distribution evaluations based on geometry, drag and image-derived wake structure. Download the JSON manifest, read the methodology, or browse the complete reproducibility files on Hugging Face. Partition sizes, provenance and a usage example are included in the WindsorML dataset record.

202617 August

Official AhmedML train, validation and test splits are now available. The release defines eight deterministic benchmark regimes: a random baseline, three nested data-efficiency subsets, and four out-of-distribution evaluations based on geometry, drag and image-derived wake structure. Download the JSON manifest, read the methodology, or browse the complete reproducibility files on Hugging Face. Partition sizes and a usage example are included in the AhmedML dataset record.

202617 August

Official DrivAerML train, validation and test splits are now available. The release provides eight deterministic benchmark regimes for a random public baseline, nested data-efficiency studies, geometry extrapolation, drag-regime extrapolation and rear-separation evaluation. Download the JSON manifest, read the methodology, or browse the complete reproducibility files on Hugging Face. The partition sizes and usage example are documented in the DrivAerML dataset record.

202620 May

HiLiftAeroML dataset preprint and huggingface repo are now online! Paper Dataset.

20255 March

All three datasets (AhmedML,WindsorML and DrivAerML) are now available on Hugging Face! Visit AhmedML, WindsorML and DrivaerML respectively.

202431 October

“WindsorML has been accepted at NeurIPS 2024! The preprint will be updated to reflect the latest version submitted to the conference”

202423 August

“DrivAerML: High-Fidelity Computational Fluid Dynamics Dataset for Road-Car External Aerodynamics” paper is now available on arxiv

20242 August

“WindsorML: High-Fidelity Computational Fluid Dynamics Dataset for Automotive Aerodynamics” paper is now available on arxiv

20242 August

“AhmedML: High-Fidelity Computational Fluid Dynamics Dataset for Incompressible, Low-Speed Bluff Body Aerodynamics” paper is now available on arxiv
